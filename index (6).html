One stroke 一笔

Every Chinese character is written in a conventional order of strokes. Here, each character is translated into a single continuous line using a simple set of drawing rules.

You don't need to read Chinese to play. Decode the strokes of each option and find the character that could have produced the line.

Characters come in short phrases. Each phrase you finish is written onto your page as one continuous line.

丨down

Variations count as their basic stroke. A hook like 亅 counts as 丨. A long falling stroke, like the right side of 人, counts as 丶. A short rising stroke counts as 一. Any stroke that bends counts as 乛.

Follow the strokes in order. 乛 rotates all following directions by 90°. A dot marks the start. Small cuts separate strokes that continue in the same direction.

Everyone plays three rounds unaided. After that, Show strokes reveals each option's stroke order for anyone who wants it.
